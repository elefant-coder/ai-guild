# Brand logos

These files are official logos and favicons of third-party products, downloaded from the sources listed in `sources.json`.
They are used only to identify the corresponding product in the catalog (nominative use). All trademarks belong to their owners; this project is not affiliated with or endorsed by them.
If you redistribute a fork and prefer not to ship them, delete this folder and set `brands` overrides in `guild.config.json` to `neutral`.
